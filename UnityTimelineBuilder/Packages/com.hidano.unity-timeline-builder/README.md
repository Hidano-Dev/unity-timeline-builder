# Unity Timeline Builder

CSV/TSV 形式の構築情報から、Unity Timeline と PlayableDirector 付き Prefab を生成する Editor 専用 UPM パッケージです。

## 開発配置

このパッケージは `UnityTimelineBuilder/Packages/com.hidano.unity-timeline-builder/` に embedded package として配置されています。Unity 6000.0 以降および `com.unity.timeline` 1.8.13 に対応します。

詳しい使い方と CSV テンプレートは、実装タスクの進行に合わせて `Documentation~` に追加されます。
